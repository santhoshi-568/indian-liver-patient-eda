
# Indian Liver Patient Records - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Indian Liver Patient Records dataset using Python.

The objective is to understand patient demographics and explore relationships between clinical attributes using data visualization.

## Dataset
Source: https://www.kaggle.com/datasets/uciml/indian-liver-patient-records

The dataset contains 583 patient records and 11 columns, including demographic information, liver function measurements and a disease classification label.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizations

### Univariate Analysis
1. Histogram - Age Distribution
2. Count Plot - Gender Distribution

### Bivariate Analysis
1. Box Plot - Total Bilirubin vs Disease Status
2. Scatter Plot - Age vs Total Bilirubin

## Key Objectives
- Understand patient age distribution.
- Analyze gender representation.
- Compare bilirubin levels across disease groups.
- Explore relationships between age and bilirubin.
